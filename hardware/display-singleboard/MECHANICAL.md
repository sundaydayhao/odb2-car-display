# 显示单板 A6：屏幕、接口与外壳配合

PCB 保持 120 × 74 mm、4 层、名义厚度 1.6 mm，板框包络为 (−31, −84.5) 至 (89, −10.5) mm。这个尺寸来自官方主控参考区和屏幕供电区的布置、接口及固定空间；7 寸是屏幕对角线，不是 PCB 外形尺寸。

F 面朝背壳，B 面朝屏幕。以下坐标从背壳侧观察，+X 向右、+Y 向下、+Z 指向背壳。屏幕正面看到的左出线触摸，在本坐标中位于右侧。板下沿不设置外部插拔口，留给底座。

## LCD、触摸与摄像头

| 接口 | 封装原点 / 方向 | 装配方向 |
| --- | --- | --- |
| J302 LCD，30P / 0.5 mm | B 面 (31, −26) mm，180° | 排线口朝 +Y，排线向 −Y 插入 |
| J308 触摸，6P / 0.5 mm | B 面 (69, −25.5) mm，180° | 排线口朝 +Y，对应屏幕正面左出线 |
| J9 摄像头，15P | F 面 (3.5, −61) mm，−90° | 竖插，沿 +Z 操作，名义连接器高 5.4 mm |

J302 插拔区预留 X=22…40、Y=−26…−17 mm；J308 为 X=64…74、Y=−25.5…−17 mm。J9 预留 X=−0.5…7.5、Y=−71…−50 mm，以及背壳方向的锁扣和弯折空间。摄像头排线折返须避开旁边 J7 麦克风的声孔，不能将麦克风盖在排线和泡棉下面。

所选商品提供的 LCM 名义尺寸为 164.86 × 99.96 mm；触摸盖板、左出线 FPC 完整尺寸和接触面仍待模组图纸或样品核对。[FPC_PLACEMENT_PROPOSAL.svg](FPC_PLACEMENT_PROPOSAL.svg) 是连接器布局示意，不是屏幕与 PCB 已精确对齐的装配图。PCB 上下接触插座和排线裸铜面必须成对确认，不能只按商品正面照片确定。

先插入 LCD、触摸、摄像头 FPC 和内部线束并锁紧，再固定主板和后盖。锁扣操作区不放加强筋；排线不夹入壳缝、螺钉或屏幕金属背板之间，也不贴着电感和发热器件折弯。

## 上侧大拨键

SW3 为 SS-12D06G5 侧拨开关，焊盘原点 (−7, −73.6) mm / 0°。本体中心相对原点偏移 (0, −7.3) mm，本体名义 12.7 × 6.4 × 6.6 mm，上沿距板框 0.4 mm；拨杆向 −Y 伸出，在上侧壁左右滑动。行程名义 2.2 mm，外伸杆长 5 mm。

外壳拨帽先按 12 × 6 mm（X/Z），槽按 15.5 × 6.8 mm、Z 中心 3.9 mm 作为样件起点。拨帽需要导向和止挡，不能把侧向载荷全部施加在电气开关上。用实物确认全行程、接触面、公差、跌落后动作和装配高度后，再冻结开孔。

SW3 控制 U401 TPS22965 的 ON 输入。J22 稳压 5 V 与 J19 调试 USB 电源分别经隔离路径汇入 INPUT_5V，再由 U401 接到 VCC_5V。扩展口 J1 若向 VCC_5V 注入电源，会绕过此开关；整机线束应从指定输入端供电。

## 外部接口与维修

| 接口 | 外壳配合 |
| --- | --- |
| J22 稳压 5 V | 左上侧；预留配套锁扣释放和线束弯折空间 |
| J19 USB Serial/JTAG | 左侧；保留编程、调试及恢复接入。USB 单独供电按维护/限载使用 |
| J18 USB HS A 母座 | 右侧，固定 Host 接法；外侧暂留 25 mm 插拔和 20 mm 插头胶壳高度包络 |
| J21 microSD | 右侧 B 面高度；开口须能推入、弹出并取卡 |
| J16 扬声器 | 左侧内部线束，合壳前插接并应力释放，与麦克风隔腔 |
| SW1 RESET / SW2 BOOT | 背壳维修孔或维修盖内可达，正常装配不预压 |
| J1 / J2、TP401…407 | 后盖维修与生产夹具接入，计入插头及探针行程 |
| J7 麦克风 | 独立短声道，与扬声器和结构振动隔离 |

只保留一个 USB HS A 母座及独立调试口，不为已删除的 Ethernet、额外 HS 或备用 FS 口留外壳开口。`enclosure.json` 和脚本导出的坐标以实际封装为准；封装原点不能直接当作插座金属口中心。

## 固定、背板与散热

| 固定孔 | 绝对中心（mm） |
| --- | --- |
| H1 | (4.5, −81) |
| H2 | (62.5, −81) |
| H3 | (−5.5, −20.5) |
| H4 | (62.5, −32) |
| H301 | (−26, −59) |
| H302 | (−26, −14.5) |

六孔名义钻孔 3 mm、焊盘外径 5 mm。H1/H2 附近较紧，采用实测外径不大于 5 mm 的绝缘小头紧固件和支撑柱，并核对螺丝刀通道；不能根据孔名称直接使用大头 M3 垫片。外壳采用一个主定位点和一个允许方向浮动的定位点，其余柱支撑紧固，避免把 PCB 顶弯。

B 面存在器件和通孔焊脚，需与屏幕金属背板保持绝缘净空。通孔脚焊后剪短并检查，导热垫不应对 LCD 玻璃或 PCB 施加弯曲载荷。当前检查覆盖 PCB 平面包络和操作空间，完整外壳高度、公差、热通路和实物干涉尚待结构样件验证。

C6 天线位于右上区域；屏幕金属背板、螺钉、金属涂层和线束应避开。`enclosure.json` 保留周边新增物体 15 mm 净空目标，需要在屏幕和外壳装配后实测无线表现。塑料后盖本身不能消除屏幕金属背板造成的屏蔽。

OBD 节点和烧录夹具仍为两个独立工程，不与本板合并。
