# 修订 I：右侧按压自锁 Nano-SIM

J1000 已由翻盖式 SIM8060 更换为 **GCT SIM8066-6-1-14-01-A**（LCSC C3032925）。使用 Nano-SIM，从侧面推入锁定，再向内按压后弹出。无需打开卡座顶盖。原理图、PCB、本地封装和 3D 模型已同步替换。

## 位置与外壳

- 位于 PCB **F 面 (8.2, 29.0) mm**，坐标以板框左上角为原点。KiCad 方向为 270°，文件可能规范化保存为 −90°。
- 入口朝**屏幕正视的右侧**，SIM 在上、TF 在下。当前 F 面朝后壳，从 F 面观察时显示在左侧；坐标与面定义更新至修订 K。
- 本体名义尺寸 13.72 × 12.29 mm，高 1.44 mm；本体入口相对板边约内缩 0.7 mm。厂商图纸给出的锁定、最深按压和弹出位置分别为相对入口 1.50、0.65、4.20 mm，即锁定后再向内按 **0.85 mm**，弹出时向外移动 **2.70 mm**。
- 外壳必须设置可伸入手指/指甲的按压凹位，并在板边外保留至少 5 mm 的初始卡片活动空间。这个空间是布局预留，不是外壳最终开孔尺寸；壳厚、屏幕盖板伸出、实际卡座入口、卡片公差和操作便利性需用样件配合确认。

## 电路与检测

| 接口 | 当前连接 |
| --- | --- |
| C1 / VCC | ML307A 的 SIM0_VCC，支持模组选择的 1.8 / 3.0 V；不可直接接 3.3 V |
| C2 / RST、C3 / CLK、C7 / DATA | 原有串联 22 Ω 与 ESD 路径保持 |
| C5 / GND、四个 SH 外壳焊脚 | GND |
| C6 / VPP | 明确不连接 |
| CD（库中 SW） | SIM0_DET；R1033 改为 10 kΩ，上拉到 MODEM_1V8 |
| R1034（新增） | 10 kΩ，从 SIM_DATA_SOCKET 上拉到 SIM0_VCC |
| C1030 | 改为 1 µF / 10 V，SIM 卡电源去耦 |

新卡座检测开关为常闭型：**空卡时 CD 接地，SIM0_DET 为低；插卡后断开，上拉为高**，与 ML307A-GCLN 手册默认“高=有卡”一致。检测使用模组 VDD_EXT 的 1.8 V 域。运行时热插拔及去抖仍需固件和实机验证。

## 封装与检查

本地封装为 `Carrier:nanoSIM_GCT_SIM8066_PushPush`。按 GCT A1 图纸修正供应商库：两个定位孔改为 Ø0.75 mm **NPTH**，七个信号/检测焊盘为 0.80 × 1.14 mm，四个固定焊脚统一为 SH/GND，庭院扩展至覆盖全部焊盘。卡座本体下增加器件面铜禁布区，禁止走线、过孔和铺铜；不改变另外三处板级规则区。

与 `b914986` 基线相比，350 个原有封装对象完全不变；J1000 换型，R1033/C1030 改值，增加 R1034。18 张其他子图、板框、隔热槽、FPC 和音频布局不变。KiCad 10.0.5：0 ERC 错误、13 个既有警告、0 物理 DRC 违规、0 SCH/PCB 差异；未布线，有 848 项未连接。见 [SIM_REVIEW.json](SIM_REVIEW.json) 和 [VERIFICATION.json](VERIFICATION.json)。

供应商 STEP 保持原字节和比例，已检查原生 3D 入口方向与焊脚位置。模型用于外形参考，不作为精密壳体配合依据。历史 SIM8060 库文件保留，但当前 PCB 和模型清单不再引用它。
