# 外接驻极体麦克风载板

本小板将已选 Goertek **B4013AM422-042 / C233793** 固定在外壳上，通过两线接主板 J7；主板 ES8311 偏置电路保持不变。载板只有咪头和两线焊盘，不另加偏置电源或数字接口。

## 文件与检查

打开 `microphone_carrier.kicad_pro`。SCH / PCB、项目符号/封装/STEP、原生 ERC / DRC / 原理图一致性报告、示意预览均在本目录。板形 Ø8 mm、板厚 0.8 mm，双面；两个 Ø1 mm 孔用于线束应力释放，不是声孔。

该快照原生 ERC 0、DRC 0、未连接 0、原理图一致性 0，两个网络四个电气节点一致。`verification.json` 记录文件哈希与检查依据；只是 CAD 检查，未完成实物录音、回流焊良率、振动及环境验证。

## 接线与安装

| 小板 | 线色 | 主板连接 |
| --- | --- | --- |
| J1.1 / MIC1.1 | 红 | J7.1 MICP，含主板提供的直流偏置及音频信号 |
| J1.2 / MIC1.2 | 黑 | J7.2 专用麦克风 return；不能随意接机壳地 |

线束为 28 AWG 双绞线，样件先取 100 mm，按实际无张力路径剪裁；一端焊小板两个 Ø0.6 mm 焊孔，另一端用 JST **GHR-02V-S** 壳、**SSHL-002T-P0.2** 压接端子，与主板 **SM02B-GHS-TB** 配套。按 pin 号检查，不能只看线壳照片判断左右。信号/专用 return 始终成对走线，不跨 C6 天线，不紧贴开关电感和扬声器功率线。

咪头先回流到载板 F 面，顶部六个 φ0.25 mm 声孔朝外壳前方；无需在 PCB 中心开声孔。线束从载板背面焊接，穿过束线孔或系线固定后折向下方出口。焊点与金属壳不得受拉；别把裸咪头直接悬空焊线。

载板放入前框左上声孔的 Ø8.4 mm 槽，F 面朝显示前方、板 F 面 Z=13 mm，声孔面 Z≈11.7 mm。用柔性绝缘环支承咪头外缘，胶和垫片不能覆盖 φ2 mm 节圆上的孔组。后方装 `microphone_retainer` 压盖，两个 M2×4 螺钉，预留 0.4 mm 绝缘缓冲垫名义空间，压紧板边而非焊点；螺纹及压缩量在样件上校准。外部 φ1.2 mm 声孔连到内部 φ4.6 mm 腔，覆盖六孔声源。导声管、密封与实际灵敏度须录音验证。

## PCB / SMT 工艺

原厂第11页定义：中心 φ0.9 mm；地内环 ID1.8 / OD2.7、外环 ID3.4 / OD3.8；两环四根 0.2 mm 铜桥连通。钢网厚 0.10 mm，中心 φ0.9 开口，两个环各用三根 0.8 mm 槽分割成 120° 扇区；本工程已实现独立 F.Paste 图形。

**中心信号用一个 Ø0.2 mm 钻孔 / Ø0.5 mm 铜环过孔引到背面，必须采用树脂填孔、铜帽整平工艺。** 它位于咪头中心焊盘，不能改成普通开口通孔或仅阻焊盖孔后直接回流，否则可能吸走锡膏。8 mm 小板需按装配厂要求拼板和加工艺边；本目录不是已经获板厂认可的生产拼板。

咪头本体 φ4 × 1.3 mm（±0.1）；模型依据原厂外形重建六孔，不是原厂公差 STEP。不要水洗/溶剂清洗声孔；回流曲线和返修条件采用原厂规格书。电气测试条件 2 V / 2.2 kΩ，工作电压 1–10 V、最大500 µA；直接给 3.3 V 不等于正确偏置，必须经过主板原有电路。

## 复跑

在上一级 `enclosure` 目录，用 KiCad Python 运行 `create_mic_carrier.py --model-source microphone-carrier/Microphone.3dshapes/B4013AM422-042_nominal.step --kiskill-root <KiSkill目录>`；它调用 KiSkill 几何验证器。用 CadQuery Python 运行 `generate_mic_model.py` 可重建六孔包络。随后用 KiCad CLI 执行 ERC、PCB DRC 加 `--schematic-parity`，导出 STEP；总装脚本会读取本目录 STEP 并摆正到前框声孔。
