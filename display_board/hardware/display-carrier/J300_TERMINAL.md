# J300 端子变更（修订 L1）

2026-09-24。J300 已改为 J301 同款 **JST B2B-PH-K-S(LF)(SN)**，立创 **C131337**，PH 2.0 mm、立式 2Pin。原理图、PCB、3D 模型及采购表同步。

- 保留 F 面原点 (121,5.5) mm、180°，1 脚 BAT_CONNECTOR（电池正极），2 脚 GND；J301 仍接 BAT_TS / GND，两个线束不得互插。
- 使用与 J301 完全相同的官方 KiCad 封装和模型。板上针座名义高度从 10.9 mm 减为 6.0 mm；1.6 mm 板背面的焊尾名义露出从 2.1 mm 减为 1.8 mm，不含焊锡、公差和线束插接高度。
- 同料号共五处，每板 5 只；100 块加 20% 备料合计 600 只。采用已记录的 2026-09-23 库存快照，未下单或锁定库存。

PH 的额定电流为 **2 A（AWG24）**。原 20 W / 7.35 A 电池负载预算不能沿用；当前没有新增 2 A 电池硬件限流。F300 原“8 A”占位撤销，标为 `TBD fuse / PH 2A`，需按线材、连接器及电池故障电流重新选型，不能把标注当成保险丝已能可靠限流到 2 A。

原 BQ25896 默认 2.048 A 充电也超过该接口额定。保留 R303 装配、R304 不装的充电禁止配置；充放电上限、复位/故障保护、温升及全功能电池模式仍为 HOLD。

检查：几何 0 违规、ERC 0 错误 / 13 条既有警告、物理 DRC 0 违规、SCH/PCB 一致性 0 违规；全部引脚网络、封装/焊盘身份和其余器件位置保持。327 个实体器件模型均可加载。PCB 仍未布线，848 项未连接。

依据：[JST PH 官方图纸](https://www.jst-mfg.com/product/pdf/eng/ePH.pdf)、[立创 C131337](https://www.lcsc.com/product-detail/C131337.html)。验证记录见 J300_TERMINAL_REVIEW.json / VERIFICATION.json。
