# 7 寸 LCD / GT911 转接板 A0

> 已整合进 [A1 单板工程](../display-singleboard/README.md)。本目录仅保留参考来源；屏幕和触摸排线现在直接插入 A1 主板的 J302 / J308，不需要制作本转接板。

打开 `display_lcd_adapter.kicad_pro`。工程包含 4 页原理图、已布线双面 PCB、本地符号 / 封装库及 `assembly.csv`。

本板是 [P4X 显示主控板](../display-mainboard/README.md) 的配套工程验证板，板框 165 × 100 mm，名义厚度 1.6 mm。参考官方 LCD Adapter Board，保留原有屏幕偏压、背光和高速走线，增加电平转换与默认关闭控制。

## 电路与默认装配

| 功能 | 器件 / 配置 |
| --- | --- |
| LCD 1.8 V | U2 ME6211C18M5G-N |
| LCD 模拟偏压 | U3 AP3012K、肖特基二极管和电荷泵，产生约 9.6 V / 18 V / −6 V / 3.2 V |
| 背光恒流 | U1 ETA1611，R12=1.1 Ω，名义电流约 182 mA |
| LCD 复位 | 新增 U4 SN74LVC1G07DBVR、C28、R39；3.3 V 主控输入，开漏输出由 R4 上拉到 LCD 的 1.8 V |
| 背光默认状态 | R24 不装，新增 R41=10 kΩ 下拉，启动时默认关闭 |
| GT911 接口 | J8 安装，J5 不装；新增 R40=100 kΩ 地址选择下拉，仍应由主控执行规定的复位时序 |
| 未用接口 | J7、R31～R36、D12 等按装配表不装；J6.3 / J6.4 空接 |

R4 安装，R37 / R38 不装。R4 在参考 PCB 上接到 1.8 V；参考 PDF 的相关版本存在标注差异，本工程以核验后的 PCB 网络和目标屏电压为准。整流 / 稳压二极管的封装编号为 1=A、2=K，已匹配原理图符号。

背光初始保留 182 mA，低于目标屏资料的 200 mA 标称值。亮度、电流、散热和资料中的功耗矛盾应通过样品测量确认后再调整 R12。

## 屏幕和连接器

目标是 WTP4C5MP07S（ZX7D00C1060M002A）的 30 针 LCD + 6 针 GT911 组合。其公开规格为 1024 × 600、400 nit、−20～70 °C；作为样机选型，不代表已完成车载高温 / 阳光可视性或长期供货验证。[厂家规格](https://img03.71360.com/w3/77q677/20250929/9cc75013e0ffa4cd305119a363cb940d.pdf?dl=1)

J2 沿用参考 BOM 的 AFC01-S30FCA-00。J8 使用参考板的 `FFC6P_0P5_UP` 焊盘几何；目前未把未经尺寸验证的替代连接器写成确定 MPN。采购时需核对 0.5 mm / 6 针 / 上接触、焊脚尺寸和排线厚度，不能只看针数。

完整针号、辅助线束和点亮顺序见 [INTERCONNECT.md](../display-mainboard/INTERCONNECT.md)。当前电源偏压来自 5 V，MIPI FFC 上的 3.3 V 不能单独供起整块屏。

## PCB 与验证

保留官方参考高速路径，恢复 MIPI 邻近地铜的约 0.14 mm 间隙，并在新增低速电路后重新铺铜。主板到面板的差分路径检查跨越已安装的 0 Ω 电阻，排除了通向空贴选路电阻的支线；不能把各网络的全部铜线长度简单相加当作有效路径。

验证结果、边界和参考来源统一记录于主控板目录的 [VERIFICATION.md](../display-mainboard/VERIFICATION.md) 与 [SOURCES.md](../display-mainboard/SOURCES.md)。这套工程还没有实板点亮或制造验证，不是量产 Gerber 放行包。
