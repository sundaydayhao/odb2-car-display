# RDA5807M FM 接收器

本驱动面向带 32.768 kHz 晶振的 RDA5807M 模块，接入「影音中心 → FM 电台」。控制器使用 ESP32-P4 Function EV Board v1.4 的独立 I²C0；板载触摸、音频编解码器及摄像头控制继续使用 I²C1 / GPIO7、8。

## 推荐接线

接线前断电，按排针编号与板上丝印确认方向。

| RDA5807M 模块 | P4 Function EV Board v1.4 | 用途 |
| --- | --- | --- |
| VCC / 3V3 | J1 第 17 脚，3V3 | 3.3 V 供电 |
| GND | J1 第 20 脚，GND | 共地 |
| SDA / SDIO | J1 第 21 脚，GPIO2 | I²C0 数据 |
| SCL / SCLK | J1 第 19 脚，GPIO3 | I²C0 时钟，100 kHz |
| L / LOUT、R / ROUT | 模块耳机插座或外接功放的左右声道输入 | 模拟音频，不接 P4 GPIO |
| ANT / FMIN | 模块对应天线接口 | 按模块说明连接天线 |

GPIO4（J1.18）继续用于 ATGM336H 的 TX → P4 RX；GPIO5（J1.16）可留作未来 GPS 配置发送。GPIO6 仍空闲。默认接线无须改动板上电阻。

SDA、SCL 应分别上拉到 3.3 V；模块没有自带上拉时，可从 4.7 kΩ 开始，短线连接。模块与 P4 的信号电平统一为 3.3 V。驱动也开启内部上拉，但不把弱内部上拉作为实际接线的替代。模块应有晶振、去耦和合适的音频输出电路；裸芯片不是直接接上四根线即可使用的模块。

RDA5807M 的 MSOP10 引脚提供模拟 L/R，I²C 不传送音频。此实现通过模块自身的耳机输出或外接功放收听，不能直接从 P4 当前 ES8311/I²S 喇叭播放电台。复用现有喇叭需另行设计音频切换或 ADC 采集路径；当前代码未实现该硬件路径。不要直接并接 L/R，也不要用 L/R 直接驱动低阻扬声器。

## 功能和行为

- 87.5–108.0 MHz，0.1 MHz 步进；滑块松手后调谐，微调和已收藏频率可直接调谐。
- 点击「开始收听」才解除静音；开机、重新连接、打开页面均不会自动播放。停止后保留当前频率，重启从 87.5 MHz 开始。
- 「自动搜台」调用芯片硬件向上搜索，不会把预置频率冒充已发现电台。芯片频段为 87.0–108.0 MHz，搜索落在 87.0–87.4 MHz 或报告失败时恢复上次频率，提示未找到其他电台。
- 显示芯片的频率反馈、RSSI 原始值 0–127、立体声标志和电台检测状态；这些标志不是音频听感或天线质量的保证。
- 选台/搜台期间静音；后台任务执行 I²C，界面可继续操作并停止搜索。新请求取消旧操作，调谐等待上限约 3 秒，搜索约 15 秒（另计 I²C 调用时间）。
- 全局音量继续位于「设置 → 声音」，0–100 映射到芯片 0–15 音量级，0 硬件静音；调谐期间的音量变化也会应用。不会在音乐页或 FM 页增加第二套音量控件。
- 开始收听 FM 会暂停 SD 音乐，播放 SD 音乐会停止 FM；语音会话及 OTA 暂停 FM，结束后手动恢复。只打开 FM 页或在停止状态预选频率不会暂停 SD 音乐。
- 没有模块时显示「接收器未接入」，禁用搜台，仍可选频和收藏。提供「重试连接」，后台约每 5 秒探测一次；连接恢复后仍静音。I²C 失联时尝试静音并报告错误，控制线物理断开时不能保证模块收到静音指令。

六个频率收藏仍使用 NVS 异步保存，去重、长按移除、保存失败保留原值。没有实现 RDS 台名/节目文本或自动保存搜到的电台。

## 实现与配置

- `display_board/main/rda5807.c`：不依赖 ESP-IDF 的协议核心，通过可注入的读写/延时/取消接口访问芯片。
- `display_board/main/fm_service.c`：I²C0 驱动、4096 字节栈的后台任务、取消和超时、状态发布、音源协调。
- I²C 使用数据手册定义的 **7 位地址 0x10**：写入从寄存器 0x02 开始，读取从 0x0A 开始，每个寄存器高字节在前，不发送额外寄存器地址。未依赖非顺序访问地址。
- 默认 32.768 kHz 晶振、50 µs 去加重、100 kHz 信道间隔、立体声自动选择、软静音、搜索阈值 8。不是其他晶振或外部时钟模块的自动识别驱动。
- `menuconfig → Vehicle P4 services` 的 `DEVICE_FM_SDA_GPIO`、`DEVICE_FM_SCL_GPIO` 默认分别为 2、3。启动拒绝 SDA/SCL 重叠、与 GPS RX 冲突或 BSP 使用 I²C0 的配置。

## 接好模块后的检查

```text
fm status
media tab fm
fm tune 98.7
fm listen
media volume 35
fm seek
fm status
fm stop
fm retry
```

`fm tune` 接受一位小数的 MHz。控制命令异步提交，`ESP_OK` 只表示已入队，完成与接收状态以随后 `fm status`/页面为准。频率 98.7 仅为格式示例，应改成本地可接收频率。无天线或室内弱信号可能无法锁台。

主机协议测试覆盖字节顺序、信道计算、音量/静音、调谐和搜索、旧 STC 标志、超时/取消、I²C 失败及无台/越界搜索的频率恢复。LVGL 主机测试使用明确的接收器状态夹具验证按钮、频率反馈、取消、顶部状态和深浅主题；它不产生或证明真实无线电接收。

当前模块尚未接线实测；实际搜台、音质、左右声道、音量与语音/SD 切换、NVS 跨重启恢复需要接好硬件后验证。本次驱动开发不自动烧录。

2026-09-20 验证：10 组 C 测试通过；LVGL 深浅主题布局及交互检查 9,553 个标签、0 错误；ESP-IDF 5.5.5 固件构建通过。应用大小 6,180,736 字节，分区剩余 110,720 字节；SHA-256 为 `c495a08c2048463ec91ef65aa8390113c556062cba9e9d97fea6c68ab35db599`。构建和 UI 验证日志位于 `build/fm-driver-*.log`。
