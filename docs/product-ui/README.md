# 商用汽车副屏交互原型

产品目标与参数优先级见 [产品规格](../COMMERCIAL_DISPLAY_SPEC.md)。

`car-companion.html` 是会话内交互原型源文件，包含驾驶、车况、胎压、行程、性能五页。
底部导航手动切换；设置入口可修改外观、动力类型、亮度和油价，轮胎设置可转换压力单位。
设计控件额外提供行驶、待连接、胎压偏低三种示例状态。

默认展示夜间「夜行霓虹」，右上角调色盘可切换三套风格，不改变当前页面：

- 夜行霓虹：青绿、荧光黄和玫红。
- 熔岩赛道：橙红、冰蓝和暖黄。
- 酸性机能：荧光黄、薄荷绿和玫红。

三套风格均有日间/夜间外观。驾驶页采用分段转速带、倾斜车速数字和切角档位标识；
车况、胎压、行程和性能页统一使用对应配色。异常仍使用红色加文字，不自动跳页。

所有数据均为产品设计样例。实时值、历史记录、预估值分别展示，断连不会把历史行程清零。
此交互原型本身没有接入车辆、手机、传感器或固件通信。
2026-09-06 已将五页配色与主要布局适配到原生 LVGL 并烧录；板端默认实时模式，
设置中可手动开启明确标注的演示模式。板端已实现范围、验证及烧录记录见 [界面实现](../UI_DESIGN.md)。

## 验证

Playwright 验证脚本：`tools/check_product_ui.cjs`。

- 800 × 480 五页、三种风格、两种外观，以及默认首屏。
- 调色盘选择与设计控件联动；换肤后保持当前页面。
- 待连接、胎压告警及告警到对应页面的跳转。
- 行程范围、燃油费用重算、胎压单位转换、自吸/涡轮车型展示。
- 736 和 360 像素宽度下的浏览预览，以及 320/360 像素宽度的告警状态。
- 检查 JavaScript 异常、横向/纵向出界、文字裁切、数字/单位重叠和导航遮挡。
- 检查禁用技术字符串不出现在可见界面，断连时转速灯带熄灭。

本次检查输出 72 张截图，无运行错误及被检测的溢出问题。结果位于 `previews/validation.json`。
`previews/light-*.png` 和 `previews/dark-*.png` 是标准 800 × 480 原型截图。
`previews/lava-*.png` 和 `previews/acid-*.png` 分别对应熔岩赛道、酸性机能风格。
窄屏重排仅方便在手机/会话中评审，不代表硬件屏幕改变了分辨率。

预览器本地检查版本位于 `build/car-companion-review.html`，由 visualize 的 `render.py`
从原型源文件生成。固件同样使用原有 `build` 目录，浏览器原型与板端布局分别验证。
