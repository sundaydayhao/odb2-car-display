# 影音中心（0.4.0）

底部第六页「影音中心」默认提供「音乐 / FM 电台」，沿用仪表的深浅外观和六种配色。在线音乐、网络电台、预置音源、自定义播放地址及对应设置、串口命令和 HTTP 下载/重连逻辑已删除。语音助手的状态和控制统一放在「设置 → 语音助手」；第七页「地图轨迹」目前仅保留地图/轨迹占位，GPS 状态在顶部状态栏，DHX30 温湿度空值在驾驶页面。

## SD 卡音乐

将 MP3 放在 SD 卡根目录或 `music` 文件夹，插卡后自动扫描，点击曲目播放。支持播放/暂停、停止、上一首/下一首、音量和列表分页；文件变化后可点「刷新文件」。尚未选曲时点击播放会选择列表第一首；不在开机或一首结束后自动播放。

仅支持 MP3，扫描上述目录的直接文件，不递归扫描子目录。音乐列表最多 128 项，文件名最多 127 个 UTF-8 字节。SD 播放无需 Wi-Fi。

暂停保留缓冲及解码位置；停止后再次播放从头开始。上一首/下一首在列表内循环。拔卡或换卡停止播放，重新插卡后需重新选曲。分段读取每次打开、读取、关闭并释放挂载引用，暂停或缓冲满时不占住 SD 卡。

音乐和小智共用扬声器。语音会话或系统升级会暂停音乐，结束后可手动重新播放。音量会自动保存。MP3 解码及采样率转换工作区使用 PSRAM，小智 Opus 编码器继续优先使用片内 RAM；分配范围按任务隔离。

## FM 电台

已添加独立页签和空白内容区域。接收硬件尚未加入，当前没有调频驱动、搜台、频率或播放控制，也不会发起网络广播请求。后续接入实际硬件后再实现。

## 设置中的语音助手

设置页使用小智头像作为状态图标，提供「开启/关闭助手」「开始对话」「结束对话」。助手开关状态跨重启保存；开启时仍可说「你好小智」，回复后直接追问，断句和空闲结束遵循小智官方服务端策略。

关闭助手会停止唤醒检测、本机麦克风处理并结束当前会话。开始对话按钮在助手关闭、未联网或已在对话时不可用；结束对话回到待唤醒状态。

## 可选摄像头

摄像头为构建配置，**默认关闭**：不创建摄像头采集任务、预览/相册像素缓冲，不显示顶部摄像头图标、设置分类或影音中心页签。

需要时运行：

```powershell
.\tools\idf55.ps1 -IdfArgs @('menuconfig')
```

在 `Vehicle P4 services → Enable camera feature and UI` 打开选项，即 `CONFIG_DEVICE_CAMERA_ENABLED=y`，重新构建并烧录。启用后增加「摄像头」页签，仍需手动打开预览，不自动采集。

启用时支持实时预览、拍照和相册。SC2336 原始照片为 1280×720 的 24 位 BMP，每张 2,764,854 字节，保存到 `photos` 文件夹；界面预览为 480×270，按比例显示。离开摄像头页关闭实时采集。

相册读取本项目生成的未压缩 24 位 BMP。照片先写 `.part` 临时文件，写入、同步、关闭成功才改名；保存和读取均在后台完成。无卡不可拍照；最多 128 张，达到上限提示在电脑整理，不自动删除照片或车辆记录。关闭摄像头配置不会删除卡内已有照片。本版不录像、不上传画面。

## 串口检查

```text
media open
media tab music
media tab fm
media files
media refresh
media local 0
media toggle
media stop
media prev
media next
media volume 35
voice on
voice start
voice end
voice off
status
```

`media local INDEX` 使用当前目录从 0 开始的曲目索引。摄像头配置打开后另可用 `media tab camera`、`camera on|off|shot`、`media photo INDEX`。

## 验证边界

主机测试覆盖 MP3/ID3 解析、目录代次与有界读取、SD 拔插界面、播放控制派发、FM 空页、设置中的语音状态和按钮、可选摄像头入口。默认关闭与启用摄像头两种 UI 配置分别构建检查。

用户当前 SD 卡没有 MP3，实板音乐听音、暂停续播、换曲及播放期间拔插仍待有音乐文件时验证。FM 尚无接收硬件，当前只验收页面入口与空白内容。摄像头开启版本的先前拍照/读取实测记录保留在 [P4 联调记录](P4_BRINGUP.md)，不代表默认固件开启摄像头。
