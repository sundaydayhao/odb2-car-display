# OBD 直脚试配基准（不是采集器生产板）

2026-09-14：根据用户要求查阅 SAE J1962 资料。用户照片为蓝色 MINI ELM327 插头正面；照片不显示内部焊尾。此目录独立于已打开的采集器 KiCad 工程，不覆盖其布局。

本试配板使用 **38.5 × 16.6 mm** 板框，**2 × 8、同排中心距 4.00 mm、两排中心距 8.60 mm**。这两个间距来自公开 SAE J1962 APR2002 图 A2 的插接面；当前 SAE 目录列出的版本为 J1962_201607，未把旧版公开图冒充最新版完整规范。

**几何假设：焊接尾脚与插接触点同轴、无弯折或错位。未证明照片中的插头满足此假设。** 板上 F.Cu 视图定义为“从插头背面朝插接方向看，宽边朝上”，上排 1–8、下排 9–16。插头正面视图左右相反，切勿按照片方向直接复制。

`obd_straight_pin_trial.kicad_pcb` 和本地 `OBD_Trial.pretty` 是只有连接器的孔位试配件，没有采集电路、供电或 CAN 布线。保留全部 16 个物理焊脚。建议试配槽孔为 **2.40 × 1.20 mm PTH**，焊盘 **3.20 × 2.00 mm**；这是针对标准触片截面的工程试配值，不是 SAE 规定的 PCB 孔尺寸。板厚、实际尾脚尺寸、加工公差、端子肩部和外壳支撑高度仍需实物验证。

电气功能标注：4 为 chassis ground，5 为 signal ground，6 为 CAN_H，14 为 CAN_L，16 为 VBAT。其余触点独立保留，不擅自并接。此试配板没有改变主采集器原理图的接地设计。

后续 A1 已按同一笔直同轴假设将孔位、电源、蓝牙和 CAN 整合并完成布线，请查看 [上一级完整采集器工程](../README.md)。此目录只保留早期机械对照件；主板另有独立 ERC／DRC／连通检查。实际尾脚、编号方向、槽孔间隙和壳体高度仍需试配确认。

## 可核验来源

- [SAE J1962_201607 官方目录与范围](https://saemobilus.sae.org/standards/j1962_201607-diagnostic-connector)
- [公开 SAE J1962 APR2002](https://law.resource.org/pub/us/cfr/ibr/005/sae.j1962.2002.pdf)：图 2 触片截面、图 3 车辆插座正面编号、图 A2 插接面中心距。它没有给出这款 MINI 外壳的 PCB 焊尾图。
- [ATTEND 原厂产品目录](https://www.attend.com.tw/data/download/file/2023%20pdf%20ATTEND-L.pdf)：同系列存在焊接型 226A-1201、弯脚 DIP 型 226A-1202，不能只凭 OBD-II 名称互换 PCB 封装。
- [ATTEND 226A-1201 原厂图纸，经销商镜像](https://img.ozdisan.com/ETicaret_Dosya/607755_912240.PDF)：提供具体型号的内部/尾部结构；未将它识别为用户照片中的型号。

使用 KiCad 10 原生 Python 运行 `generate_reference.py` 可重建试配板及候选封装；脚本在保存前核对板框、16 个针号、4.00/8.60 mm 网格及铜边距。检查和渲染输出在本目录 `build/`，不作为生产文件。

实际检查：KiCad 10.0.5 加载与导出通过；保存后逐针坐标一致；试配板 DRC 0 项、未连接项 0 项（每个针位孤立，无电子电路）；黑白铜层／丝印渲染已检查，无针号或文字重叠。无对应试配原理图，因此不把 ERC 列为通过项。与主板相比仅新增本目录，不覆盖其设计文件。
