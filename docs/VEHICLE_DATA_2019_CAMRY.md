# 2019 凯美瑞 2.5L 汽油版：参数接入范围

2026-09-20 用户确认动力版本。当前链路为车辆 CAN → ELM327/B02-Z → BLE → P4/C6，屏幕不直接接收全车原始 CAN。
标准 PID 有读取实现不等于该车一定支持；每次连接先查询能力位图，再只轮询所选 ECU 声明支持的参数。

## 已接入的标准读取

| 界面或计算输入 | Mode 01 PID | 换算 | 证据/限制 |
| --- | --- | --- | --- |
| 车速 | 0D | A km/h | 9 月 13 日实车文件已有有效样本 |
| 转速 | 0C | (256A+B)/4 rpm | 同上 |
| 水温 | 05 | A−40 ℃ | 同上 |
| 发动机负荷 | 04 | 100A/255 % | 该次 0100 能力位已声明，尚未采样验证 |
| 节气门 | 11 | 100A/255 % | 同上 |
| 进气温度 | 0F | A−40 ℃ | 同上 |
| 油量 | 2F | 100A/255 % | 等待本车 0120 能力与实际回复 |
| 控制模块电压 | 42 | 256A+B mV | 等待 0140 能力与回复；不是精密电池测量 |
| 机油温度 | 5C | A−40 ℃ | 等待 0140 能力与回复 |
| 进气歧管绝对压力 | 0B | A kPa | 已有 7E8 的能力值 BE1FA013 **未声明此 PID** |
| 大气压力（计算输入） | 33 | A kPa | 等待 0120 能力与回复 |
| 燃油流量（计算输入） | 5E | (256A+B)/20 L/h | 等待 0140 能力与回复；不使用固定空燃比代算 |

读取和换算在 `display_board/main/obd2.c`、`obd2_decode.c`，界面映射在 `ui.c`。
标准 PID 的公式参考 [DashLogic 厂商参数表](https://www.dashlogic.com/docs/technical/obdii_pids)，
能力发现和标准/厂家服务的区别参考 [Emtron 文档](https://docs.emtronaustralia.com.au/displays/functions/obd2/index.html)。
实车依据见 [原始采集说明](OBD_CAPTURE_2026-09-13.md)，不能把能力声明当作有效实时样本。

## 计算得到的显示值

| 显示值 | 输入与规则 |
| --- | --- |
| 即时油耗 | ECU 燃油流量 ÷ 车速 × 100；车速低于 5 km/h 时不显示 L/100 km |
| 平均油耗 | 车速和燃油流量同时有效的连续窗口内，耗油量 ÷ 距离 × 100；至少累计 100 米 |
| 采集里程、时长、平均车速 | 对有效车速按单调时间积分；平均速度含停车时间 |
| 耗油量 | 对 ECU 燃油流量按时间积分；断油的有效零值保留 |
| 怠速时长 | 车速为零且转速大于零时累计；速度或转速失效即重置该项连续窗口 |
| 相对进气压力 | 歧管绝对压力 − 同时有效的大气压力；不用固定 100 kPa 冒充实测大气压力 |

积分仅保留连续、未过期的数据段。每步时间不得超过 1 秒，速度、燃油、怠速分别维护连续窗口；
对应输入失败、过期或时间异常后重新累计。不同输入起始时刻可能不同，因此平均油耗另用同一有效窗口的油量和里程，
不直接相除两个独立累计值。连接中断清空全部采集统计。界面明确标注“连续采集统计 · 中断后重新累计”。
这些值不是车机总里程，也不是跨天、跨重启的完整行程账本；“今天”“本箱”保持未读取。
既有油价是固定参考值 8.15 元/L，花费只是采集耗油量乘此参考油价，不来自 CAN，也不是实际账单。

## 仍不能据此接入的项目

- 四轮胎压、胎温、变速箱温度、实际挡位、机油压力：缺少经本车验证的厂家 PID、CAN 定义或相应传感器数据。
- 剩余续航：仅油量百分比不够，还需可靠可用油量和油耗模型。
- 横向/纵向 G、0–100 等性能记录：当前没有对应传感器与经过验证的测量链路；低速 OBD 轮询不能作为精确性能仪。
- GPS 位置、地图轨迹：已实现独立 ATGM336H-5N 串口接入，模块待接线实测，见 [地图说明](MAP.md)；不从通用发动机 OBD 参数推断。
- 故障码详情、保养信息、油耗历史曲线：本次未实现对应诊断服务或历史记录。

上述项目保留未读取状态。当前仅发送读取 PID 和适配器初始化/会话命令，没有车型私有 ECU 写入、清码或控制动作。

## 本次界面与音量变更

- 音乐列表采用固定五行分页，显示序号、文件名、当前曲目标记和总数；移除刷新按钮，沿用 SD 插拔自动扫描与版本校验。
- 顶部音乐图标显示播放/暂停/等待/错误状态，点击进入影音中心；顶部扬声器点击进入“设置 → 声音”。
- 全局音量 0–100，0 为静音；音乐与语音助手共用，复用已有 `media/volume` 保存值，重启恢复。
- 地图页删除内层重复标题，扩大地图区域；行程改用列表图标，与地图定位图标区分。

## 验证方式

`tools/run_host_tests.ps1` 覆盖生产解析器、B02-Z 分片握手、连续积分/过期/重连、轮询公平性与失败退避、
以及 LVGL 点击、暂停状态、声音入口、音量拒绝回滚和 SD 插拔。`tools/idf55.ps1 build` 构建 P4 固件。
这些属于主机测试和固件构建；新功能的实际扬声器听感、板端 BLE 连接和新增 PID 仍需上板/实车验证。
