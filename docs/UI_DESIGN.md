## 文件职责

- `display_board/main/ui.c`：屏幕、触摸驱动、任务锁以及车辆数据到显示模型的映射。
- `display_board/main/dashboard.c`：五页 LVGL 布局、三套配色、手动导航、状态栏与独立演示数据。
- `display_board/main/service_panel.c`：唯一设置入口、分类页面、屏幕配网与服务操作；`ui.c` 执行持久保存。
- `display_board/main/dashboard.h`：不依赖车辆协议或硬件驱动的显示数据模型。
- `display_board/main/dashboard_text.h`：全部中文界面文案。
- `display_board/main/fonts/`：生成后直接编入固件的字体及 OFL 授权。

## 中文字体

原有内置 SimSun 是有限字符的子集，不包含所有简体中文文案。现在使用项目
LVGL 9.2.0 自带的 Noto Sans SC 源字体，提取实际使用的字符，生成 18/22 像素
抗锯齿中文字库。字号较大的数字使用 Montserrat。无需给开发板安装额外字体。

新增中文文案后执行：

```powershell
node tools/generate_ui_fonts.mjs
```

转换器固定为 `lv_font_conv@1.5.3`。字体生成不属于日常固件编译的联网依赖；
生成的 C 文件保留在工程中。字体来源与转换格式参见
[Noto](https://notofonts.github.io/noto-docs/website/use/) 和
[LVGL 字体转换器](https://github.com/lvgl/lv_font_conv)。
