# A3：焊接、探针与定位接口

本版已经落实背面测试点、5 V 检测、定位孔及顶面支撑区；PCB 文件的电气连通、槽孔和阻焊开窗检查通过。**现有 OBD 插头的实际尾脚尺寸、塑料包络及板到插头间距尚未取得，不能确认它一定能插入焊接，也不能确认焊后能接触全部测试点。** 当前交付是可供插头供应商核对的 PCB 接口定义。

## 坐标和探针

板框为 38.5 × 16.6 mm，四层、板厚暂定 1.6 mm。以下均从正面看，以板框左上角为原点，x 向右、y 向下；测试焊盘实际在背面。翻面且保持同一上边朝上时，针床观察坐标 x = 38.5 − 正面 x，y 不变。CSV 已提供两种坐标，不得重复镜像。

9 个测试点集中在 y = 15.0 mm，间距 2.0 mm，直径 1.0 mm；只有背面铜与阻焊开窗，不上锡膏。测试焊盘内不打过孔，附近过孔的钻孔边缘与焊盘至少相隔 0.1 mm；TP5 内原有过孔已移出，避免探针卡入钻孔。按正面投影从左到右：

| 触点 | 网络／用途 | x（mm） |
|---|---|---|
| TP1 | GND | 15.2 |
| TP2 | +3V3，高阻检测 | 17.2 |
| TP9 | +5V，高阻检测 | 19.2 |
| TP7 | USB_DM / GPIO18 | 21.2 |
| TP8 | USB_DP / GPIO19 | 23.2 |
| TP3 | EN，开集电极复位控制 | 25.2 |
| TP4 | BOOT / GPIO9，开集电极下载控制 | 27.2 |

TP2、TP9 均为测量输出点，不给它们注入电源。供电仍经过 OBD 16 脚及主板保护电路，4/5 脚接地；USB VBUS 不接主板。停车电流测试需断开可能反向供电或影响休眠的 USB、UART、EN、BOOT 与测量支路，详见 [夹具流程](../obd-programming-fixture/README.md)。

## 定位与支撑

| 特征 | 正面投影中心（mm） | PCB 尺寸／作用 |
|---|---|---|
| H1 | 2.0, 15.0 | Ø1.2 mm 非金属化圆孔，主定位 |
| H2 | 34.3, 15.0 | 1.6 × 1.2 mm 水平非金属化槽孔，沿两孔连线释放公差 |
| 支撑 A | 15.0, 15.0 | 顶面 x=14.4–15.6、y=14.4–15.6 mm |
| 支撑 B | 32.5, 15.0 | 顶面 x=31.9–33.1、y=14.4–15.6 mm |

定位孔中心距 32.3 mm，位置不对称，用于防反装；它们不是螺丝孔。可先用 Ø1.0 mm 定位销评估，最终销径、导入倒角和针座位置公差必须随板厂成品孔公差及探针规格冻结。两处支撑区已在 PCB 中设置顶层禁焊盘、禁过孔规则；允许阻焊覆盖的走线，只能使用平面绝缘软压块，不能以金属尖头施压。实物压紧后应检查板弯及焊点应力。

## 插头焊后可触及性

PCB 的 Dwgs.User 标出所需背面探针窗口：**x=14.2–32.2、y=13.9–16.4 mm，共 18.0 × 2.5 mm**。这表示插头和外壳必须让出的空间，并不代表已存在这样的开口。插头焊好后，从外部到整排触点必须有连续无障碍的探针路径，定位销也必须能到达 H1/H2。

先按至少 3 mm 的背面探针工作空间做结构评估，最终由所选针的有效行程、针座外形和装配公差确定。背面有元件，插头塑料到 PCB 的间隙还应覆盖实际最高背面元件及约 0.5 mm 初始装配余量；不能仅凭铜层图确定元件高度。尾脚有效长度须同时容纳该间隙、1.6 mm 板厚以及工艺要求的焊脚伸出量。

现有插头若挡住上述区域，应换合适的尾脚／壳体结构或调整装配工序。**在实物试配通过前，首烧顺序保持 SMT 后、焊 OBD 插头前。** 焊完插头后用配对 OBD 母座供电／CAN 加 BLE 空口复测。不能用这个工序安排替代“焊后触点可达”的实测结论。

右上角 x=35.25–38.5、y=0–5.25 mm 为射频净空；插头金属、夹具金属压块和定位结构均不得侵占。本文没有冻结 CNC／3D 打印底座加工尺寸。

## OBD 触点能否焊接

| PCB 检查项 | A3 文件结果 |
|---|---|
| 16 个实体孔 | 金属化长圆槽孔，名义成品孔 2.4 × 1.2 mm |
| 铜焊盘 | 3.2 × 2.0 mm，1 脚矩形，其余长圆形 |
| 名义环宽 | 两轴均 0.4 mm，实际值须计入板厂钻孔／铜图公差 |
| 孔位 | 同排 4.0 mm；两排 8.6 mm；现用直尾脚假设 |
| 表面开窗 | 正反面均有阻焊开窗；无锡膏层 |
| 关键电气脚 | 4/5=GND，6=CAN_H，14=CAN_L，16=VBAT；其余为实体未接电气脚 |
| 文件检查 | 完整 ERC、DRC、未连接、原理图一致性均为 0 项 |

本轮发现并修正原有生成器的阻焊问题：KiCad Python 的 `LSET.AllCuMask()` 返回共享对象，直接加入 Mask 层会污染该对象，使保存后的文件丢失预期的开窗。现改为复制层集合再加入 F.Mask / B.Mask，并在独立进程重新加载 PCB 后检查全部 16 孔。普通连通性 DRC 没有发现这一问题，因此额外加入了制造结构断言。

据此可以确认 **PCB 文件提供了可焊接的镀铜槽孔与双面焊盘结构**。但对用户手里的插头，还必须核对：

1. 厂家尾脚中心位置与上述孔位吻合，且观察方向与针号对应，尤其是 6/14/16 脚。
2. 尾脚截面及圆角，在尺寸公差和装配偏差下仍能进入长圆孔。矩形脚不能只检查宽小于 2.4、厚小于 1.2；四个角也要落在长圆孔内。
3. 尾脚材料／镀层可焊，长度满足安装间隙及板厚；插头塑料能够承受规定焊接温度和时间。
4. 焊后没有塑料挡住焊盘、探针和定位结构；焊料、金属脚不碰元件或侵占天线净空。

OBD-II 的名称不能单独确定厂家的 PCB 尾端封装。例如 [ATTEND 的官方 OBD 系列](https://www.attend.com.tw/zh-tw/product.php?act=view&id=10) 同时提供焊线包胶和直角 DIP 等尾端结构。因此现有 4.0 / 8.6 mm 孔距不是对任意 OBD-II 插头的兼容承诺。
