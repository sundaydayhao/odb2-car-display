# 影音中心（0.4.0）

底部第六页「影音中心」提供「音乐 / FM 电台 / 摄像头」，沿用仪表的深浅外观和六种配色。语音助手和闹钟位于设置中；小智可查询车辆指标、控制音量/音源、设置闹钟和拍照，见 [小智设备工具](VOICE_CONTROL.md)。第七页「地图轨迹」提供离线中国概览与独立串口 GPS 轨迹，见 [地图说明](MAP.md)。GPS 状态在顶部状态栏，DHX30 温湿度空值在驾驶页面。

## SD 卡音乐

将 MP3 放在 SD 卡根目录或 `music` 文件夹，插卡后自动扫描，点击曲目播放。支持播放/暂停、停止、上一首/下一首和列表分页；插拔自动更新，已移除「刷新文件」按钮。列表每页五首，按文件名排序，显示序号、曲目名、当前曲目标记和总数。尚未选曲时点击播放会选择列表第一首；不在开机或一首结束后自动播放。

仅支持 MP3，扫描上述目录的直接文件，不递归扫描子目录。音乐列表最多 128 项，文件名最多 127 个 UTF-8 字节。SD 播放无需 Wi-Fi。

暂停保留缓冲及解码位置；停止后再次播放从头开始。上一首/下一首在列表内循环。拔卡或换卡停止播放，重新插卡后需重新选曲。分段读取每次打开、读取、关闭并释放挂载引用，暂停或缓冲满时不占住 SD 卡。

音乐、小智和闹钟共用扬声器及全局音量，统一在「设置 → 声音」调节 0–100 音量，0 为静音，自动保存并在重启后恢复。顶部扬声器图标可快捷进入设置；播放器内不增加音量滑块。顶部音乐图标显示播放/暂停状态，点击回到影音中心。语音、闹钟或系统升级会暂停音乐；小智明确要求播放的操作在本轮回复后执行，其余情况手动恢复。MP3 解码及采样率转换工作区使用 PSRAM，小智 Opus 编码器继续优先使用片内 RAM。

## 在线 MP3

支持用户提供的 HTTP/HTTPS MP3 直链，使用流式下载和现有解码器，最近音源保存到 NVS。可通过小智或 `media online URL "TITLE"` 设置并播放，之后点击音乐页「在线播放」使用已保存地址。没有地址时明确提示设置，不使用虚构或演示歌曲。未接入音乐平台曲库搜索、DRM、HLS 或歌单网页；按歌名联网点歌仍需用户提供音乐服务/API。播放状态与本地音乐共用左侧播放器，SD 列表保留在右侧。

## FM 电台

提供深浅主题的频率选择页：大字频率、刻度滑块、0.1 MHz 微调（支持按住连续调整），选择范围 87.5–108.0 MHz，到边界停止。
右侧六个常用频率位，点空位收藏当前频率、点已收藏项选频、长按移除；重复频率不会占用另一位置。
收藏经后台任务写入 NVS 的 `display/fm_slots_v1`，成功后才更新列表，重启恢复；保存期间锁定收藏操作，失败保留原列表并提示重试。
频率选择保留到本次运行结束，重启从 87.5 MHz 开始。顶部扬声器仍可进入全局声音设置。

已接入 RDA5807M 接收驱动：I²C0 使用 GPIO2 / SDA、GPIO3 / SCL，支持调谐、硬件搜台、静音、全局音量和信号/立体声反馈。模块未接入时禁用搜台并显示「重试连接」，选频与收藏仍可使用。收藏是用户保存的频率，不代表已发现或收到电台。
开始收听 FM 会暂停 SD 音乐，播放 SD 音乐、语音会话或 OTA 会停止 FM；进入页面不自动收听。电台声音从模块的模拟 L/R 输出到耳机或外接功放，当前不进入 P4 板载喇叭。接线、协议和验证边界见 [FM 接收器](FM.md)。

## 设置中的语音助手

设置页使用小智头像作为状态图标，提供「开启/关闭助手」「开始对话」「结束对话」。助手开关状态跨重启保存；开启时仍可说「你好小智」，回复后直接追问，断句和空闲结束遵循小智官方服务端策略。

关闭助手会停止唤醒检测、本机麦克风处理并结束当前会话。开始对话按钮在助手关闭、未联网或已在对话时不可用；结束对话回到待唤醒状态。

## 摄像头

摄像头为构建配置，**当前及默认配置已启用**。影音中心第三个页签提供预览、拍照和相册，设置中也有控制入口。开机不自动采集，页面点击或语音命令才启动摄像头。

需要更改功能配置时运行：

```powershell
.\tools\idf55.ps1 -IdfArgs @('menuconfig')
```

在 `Vehicle P4 services → Enable camera feature and UI` 修改 `CONFIG_DEVICE_CAMERA_ENABLED` 后重新构建。关闭选项时不创建采集任务或预览缓冲，并隐藏相关入口。

启用时支持实时预览、拍照和相册。SC2336 原始照片为 1280×720 的 24 位 BMP，每张 2,764,854 字节，保存到 `photos` 文件夹；界面预览为 480×270，按比例显示。离开摄像头页关闭实时采集。

相册读取本项目生成的未压缩 24 位 BMP。照片先写 `.part` 临时文件，写入、同步、关闭成功才改名；保存和读取均在后台完成。无卡不可拍照；最多 128 张，达到上限提示在电脑整理，不自动删除照片或车辆记录。关闭摄像头配置不会删除卡内已有照片。本版不录像、不上传画面。

```text
media open

media tab fm
fm status

media files

media volume 35
voice on

voice end
voice off
alarm status
alarm at 07:30 daily

```

`media local INDEX` 使用当前目录从 0 开始的曲目索引。摄像头可用 `media tab camera`、`camera on|off|photo`、`media photo INDEX`。在线示例域名须替换为实际 MP3 直链。

## 验证边界

主机测试覆盖 MP3/ID3 解析、目录代次与有界读取、SD 拔插界面、播放控制派发、FM 频段边界、收藏/去重/长按移除、异步保存失败及跨页完成、接收器未连接/就绪/收听/搜台/异常状态、设置中的语音状态和按钮、可选摄像头入口。RDA5807M 协议核心另有模拟 I²C 测试，覆盖取消、超时和失败恢复。

功能模型与界面通过主机验证，实际小智云端调用、网络 MP3 听音、闹钟提示音/重启恢复、摄像头与语音并发需要本次固件的实板验证。FM 接收、模拟音频听音和 NVS 跨重启恢复仍需接线后上板确认。以前版本的摄像头实测记录保留在 [P4 联调记录](P4_BRINGUP.md)，不代替本次固件验证。
