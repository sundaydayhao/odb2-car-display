## 网络与配套边界

- LCD 按用户 LCM-070WS209-A0 PDF：CLK=17/18，D1=20/21，D0=23/24；D2/D3 明确 NC。28/29 接 LCD_1V8，RESET/STBYB 经 TXU0102 转换。LCD 偏置、背光和厂商两 lane 初始化仍未完成。
- 触摸参考口：1 RESET/control、2 3.3 V、3 GND、4 INT、5 SDA、6 SCL。R1210～R1215 / C1210～C1211 已移至 F 面座旁。**实际购买的触摸总成针序、电压和控制器尚未确认**。
- SC2336 摄像头：D1−/+=3/4、CLK−/+=6/7、D0−/+=9/10；1/2/11/12/18 为 NC。1.8/2.8 V、24 MHz 和低压控制转换仍待完成。
- 完整逐针映射仍见 FPC_PIN_MAP.csv；本次没有改变上述引脚网络。

## 插座来源

[XUNPU 双接触系列](https://www.xunpu.com.cn/product/413.html)及[系列尺寸图 Rev A](https://datasheet.lcsc.com/datasheet/pdf/efde5e3dfa7498fa4d87ef03a639edf6.pdf)。焊盘与模型沿用已核对的修订 F：信号焊盘 0.30×1.20、固定脚 2.00×1.80、排距 3.25 mm，STEP Y 偏移 +1.625 mm。

厂家尾宽 15.50±0.05、厚度 0.30±0.02 mm 与 LCM 图的 ±0.10 / ±0.05 mm 公差不同；尾部补强长度也须配套确认。名义 2.10 mm 插入量只用于本次定位，不替代真实完全插入状态的核对。

修订 J 当前 PCB 350 个电路封装＋4 安装孔，0 走线、0 铜区、3 板级规则区＋1 个 SIM 封装内规则区，848 项未连接；原生间距检查与原理图一致性 0 违规。ERC 0 error / 13 个既有孤立接口 warning。仍是未布线工程草稿。
