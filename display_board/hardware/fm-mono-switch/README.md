# SGM3718 单声道 FM 音源切换小板

**状态：电气草稿。用户已选择把现有成品 FM 模块焊在同一块小板上；正在等待模块型号、外形尺寸、焊盘间距和引脚顺序。不能据此打板。**

设计范围：ESP32-P4 Function EV Board v1.4；拆除 R83、R84 后接入切换小板，复用板载 ES8311、NS4150B 和原喇叭。此目录不修改已有主板或固件。

## 已有文件与边界

- `wiring-draft.pdf` / `wiring-draft.png`：已按“成品模块安装到小板上”的最新要求更新的电气接线草图。

- `fm_mono_switch.kicad_pcb`：32 × 26 mm 切换核心的初步摆放，**未布线、未加入 FM 模块、不是最终板框尺寸**。不能直接用于生产。
- `Mono.kicad_sym` / `Mono.pretty`：按 SGM3718 厂商数据手册创建的符号和推荐焊盘；UTQFN-10，1.8 × 1.4 mm，0.4 mm 引脚间距。

生成器在 `tools/fm_mono_switch/`。`generate.py` 会重建并覆盖核心原理图、初步摆放和 BOM；完成手工布线后不要直接重跑。接线图由 `draw_wiring.py` 生成。

## 外部接线

先断电，**拆下 R83 和 R84 两颗 0Ω 电阻**，保留 C39、C40、C58、C59、R146、R147。

| 小板信号 | P4 开发板焊点 | 识别依据 |
|---|---|---|
| CP / CODEC_P | R83 的 ES8311 侧 | 通向 C39 的 R83 侧焊盘 |
| CN / CODEC_N | R84 的 ES8311 侧 | 通向 C40 的 R84 侧焊盘 |
| AP / AMP_P | R83 的功放侧 | 通向 C59 的 R83 侧焊盘 |
| AN / AMP_N | R84 的功放侧 | 通向 C58 的 R84 侧焊盘 |
| 3V3 | J1.17 | 给小板 SGM3718 和适配的 3.3 V FM 模块供电 |
| GND | J1.20 | 共地 |
| SEL | J1.15 / GPIO6 | 音源选择 |
| SDA | J1.21 / GPIO2 | 转接成品模块 SDIO |
| SCL | J1.19 / GPIO3 | 转接成品模块 SCLK |

上表 J1 是 **P4 开发板的 J1 排针**，不要与切换核心原理图的 J1 连接器混淆。模块小板定稿时会统一整理接口名称。

焊盘方向以断电后的导通测试为准，不根据图片左右猜测。每条音频支路需要拆下电阻两侧各一根线，总共四根。细软线焊接后需固定，避免拉脱开发板焊盘；模拟线尽量短，远离屏幕、背光、USB 和无线天线。

## 电气方案

SGM3718 的两个 SPDT 开关一起切换**一个单声道功放的两根输入线**：

| SGM3718 引脚 | 连接 |
|---|---|
| 1 V+ | 经过 10Ω 和本地去耦的 3.3 V |
| 2 NO1 | FM L/R 各经过 1µF 和 10kΩ 后合成的单声道 |
| 3 COM1 | AP |
| 4 IN1 | SEL |
| 5 NC1 | CP |
| 6 GND | GND |
| 7 NC2 | CN |
| 8 IN2 | SEL |
| 9 COM2 | AN |
| 10 NO2 | 经过 4.3kΩ 到 GND 的 FM 参考端 |

SEL 有 100kΩ 下拉。GPIO6 低电平默认接 ES8311（MP3/小智），高电平接 FM。FM 的 L/R 不直接短接；合成后为单声道。小板不新增扬声器功放，扬声器仍接开发板 J16。

SGM3718 在本设计中只使用 3.3 V；其负模拟信号范围与供电相关，不能把 3.3 V 条件下的负摆幅指标直接套到 5 V。SGM3718 的微型无引脚封装建议贴片回流或热风焊接。

## 软件切换要求

原板功放使能已经连接 GPIO53，无须再增加该 GPIO 的飞线。切换前静音/关闭功放，修改 GPIO6，待模拟节点稳定后恢复功放；具体延时和淡入淡出需实物听感及示波器验证。

FM 模式仍需开启原 NS4150B 功放。现有 FM 固件不包含本小板的 GPIO6 音源切换及完整 PA 协调，本次未修改固件。硬件接好后需要另行集成；音量匹配、开关爆音、接收灵敏度均尚未实测。

## 已完成检查与待办

切换核心几何检查通过，原理图 ERC 0 违规；原生 KiCad XML 网表 52/52 个器件引脚与设计意图相符；参考标号无重复或未注释器件，多单元检查无缺失。以上检查仅覆盖已有切换核心，不能代表最终模块小板通过。

待确认：成品 FM 模块型号/购买链接、长宽、焊盘中心距、引脚排列（必须注明查看方向）、天线接口及底部元件高度。RDA5807M 裸芯片数据手册没有这些模块机械信息。

拿到信息后：建立真实模块封装，加入模块供电/I²C 转接，调整板框与安装区，再布线、铺地、运行完整 ERC/DRC、核对装配图并导出打样资料。当前未导出 Gerber 或发布生产文件。
